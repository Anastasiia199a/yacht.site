# Заявки, письма и ИИ-ассистент: Google Таблица + Apps Script

**Как работает.** Один скрипт Google Apps Script обслуживает весь сайт:

- **Заявка с формы** (внизу сайта или в чате ассистента) → новая строка на листе **Leads** → письмо Илье о новой заявке → **письмо человеку, который оставил заявку**, с благодарностью и копией его формы.
- **ИИ-ассистент** → вопрос уходит в Gemini вместе с базой знаний (`apps-script/knowledge-base.md`, она же вшита в код скрипта). Ассистент отвечает по-английски и только по этой базе. Все вопросы сохраняются на листе **Chat log**.

Ключ Gemini хранится **только** в настройках скрипта: в коде сайта и на GitHub его нет.

Пока скрипт не подключён, ассистент на сайте уже работает и отвечает встроенными ответами из базы знаний. Форма в это время пишет, что не подключена, и предлагает Telegram.

Время: около 15 минут.

---

## 1. Создайте таблицу и вставьте скрипт

1. Откройте https://sheets.new тем Gmail, куда должны приходить заявки. Назовите таблицу, например «Ilya Belov — leads».
2. Меню **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте код из
   [`apps-script/Code.gs`](https://raw.githubusercontent.com/Anastasiia199a/yacht.site/main/apps-script/Code.gs) (откройте ссылку, выделите всё, скопируйте).
4. Нажмите 💾 **Сохранить** и назовите проект «Ilya website».

## 2. Получите бесплатный ключ Gemini

1. Откройте https://aistudio.google.com/apikey тем же Google-аккаунтом.
2. **Create API key** (если попросит проект, создайте новый).
3. Скопируйте ключ: длинная строка, обычно начинается с `AIza…`.

⚠️ Ключ — это пароль. Не вставляйте его в код сайта, на GitHub, в скриншоты и не присылайте в чат, даже Claude.

## 3. Сохраните ключ в скрипте

1. В Apps Script слева ⚙️ **Настройки проекта**.
2. Внизу **Свойства скрипта → Добавить свойство скрипта**.
3. **Свойство:** `GEMINI_API_KEY`, **Значение:** ваш ключ → **Сохранить**.

## 4. Дайте разрешения и проверьте

1. Вернитесь в редактор (`< >` слева), вверху выберите функцию **testSetup** → **▶ Выполнить**.
2. Google попросит доступ: **Проверить разрешения** → ваш аккаунт.
3. «Google не проверял это приложение» — это нормально, скрипт ваш. **Дополнительные настройки → Перейти на страницу «Ilya website» (небезопасно) → Разрешить**.
4. В **Журнале выполнения** должно быть:
   - `API key found: true`
   - `Gemini says: …` — ответ про менторство и гарантию работы
   - `{"ok":true}`
5. В таблице появятся листы **Leads** и **Chat log** с тестовыми строками, а на почту придут **два письма**: «New request: Test Visitor» (это письмо Илье) и «Thank you for registering — Ilya Belov» (так выглядит письмо посетителю).

**Если `Gemini says: null`:** слева **Выполнения**, откройте последнюю запись. Если там `model not found`, модель переименовали: на https://ai.google.dev/gemini-api/docs/models выберите актуальную модель «Flash» и замените название в строке `const GEMINI_MODEL = '…'` в начале кода.

## 5. Опубликуйте как веб-приложение

1. **Начать развертывание → Новое развертывание → ⚙️ → Веб-приложение**.
2. **Выполнять как:** Я. **У кого есть доступ:** **Все** (иначе сайт не сможет отправлять заявки).
3. **Начать развертывание** и скопируйте URL, он заканчивается на `/exec`.
4. Проверьте: откройте URL в режиме инкогнито. Должно быть `{"ok":true,"message":"Ilya Belov website backend is running","ai":true}`.

## 6. Подключите к сайту

Пришлите URL Claude: он вставит его в `src/lib/backend.ts` (строка `export const BACKEND_URL = …`), запушит на GitHub и проверит форму и ассистента.

## Полезно знать

- **Письма о заявках** приходят на Gmail владельца скрипта. Другой адрес можно вписать в `NOTIFY_EMAIL` в начале кода. Если в письме нажать «Ответить», ответ уйдёт посетителю.
- **Письма посетителям** уходят с вашего Gmail от имени «Ilya Belov» (`SENDER_NAME`). Бесплатный Gmail отправляет из скриптов до 100 писем в день; на каждую заявку уходит 2 письма, то есть до 50 заявок в день.
- **Изменили базу знаний или код?** Отредактируйте `apps-script/knowledge-base.md` и попросите Claude пересобрать `Code.gs`, или поправьте текст прямо в константе `KNOWLEDGE` в редакторе. Затем **Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**. URL останется прежним.
- **Защита:** в форме скрытое поле-ловушка для ботов и обязательное согласие на связь. Ассистент ограничен 40 сообщениями на посетителя за 6 часов и 800 в день на весь сайт. Если ИИ недоступен, отвечают встроенные ответы.
- **Приватность:** бесплатный тариф Gemini Google может использовать для улучшения моделей. Поэтому ассистент не собирает телефоны и email в тексте чата: контакты идут только через форму прямо в таблицу, в Gemini они не попадают.
- **Что убрано из базы знаний для ассистента:** упоминания России (по просьбе убрать их с сайта) — «поездка из России на Сейшелы» стала «совместной поездкой на Сейшелы». Добавлены Telegram @anestezia7 и правила работы с формой. Исходная база не изменялась.
